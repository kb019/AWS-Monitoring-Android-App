# Cloud Monitor UI

React + TypeScript + Vite frontend for the Cloud Infrastructure Monitoring project.

## Quick Start

```bash
cd apps/web
npm install
```

Create a `.env` file with the API base URL:

```
VITE_API_URL=http://localhost:8080
```

Run the dev server:

```bash
npm run dev
```

## Scripts

- `npm run dev` - start local dev server
- `npm run build` - typecheck and build production assets
- `npm run lint` - run ESLint
- `npm run preview` - preview the production build

## Notes

- The backend API and any generated OpenAPI clients live outside this folder.
- See the root `README.md` for project-wide context and docs.
