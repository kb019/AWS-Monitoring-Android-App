# Mobile App (Planned)

This repo includes a starter React Native screen for the EC2 Instances list,
implemented with mock data while the backend and OpenAPI spec are finalized.

Current UI:
- Instances list screen: `apps/mobile/src/screens/InstancesListScreen.tsx`
- Mock data source: `apps/mobile/src/data/mockInstances.ts`

Proposed structure:
- `apps/mobile/src` for shared React Native code
- `apps/mobile/ios` and `apps/mobile/android` generated by RN tooling

Next step:
- Wire the screen into the mobile app scaffold (Expo or React Native CLI) and
  replace `mockInstances` with the OpenAPI client.
