# AWS Account Setup (Sprint 1)

## Objective
Set up AWS account

## Steps Performed
- Created AWS account using college email ID.
- Selected Free Tier (Basic Support Plan).
- Chose default region (us-east-2).
- Created IAM group with AmazonEC2FullAccess permission.
- Added two IAM users (Dhairya_AWS & Shrinidhi_AWS) to aws-team group.
- Created a separate cloud-monitor-user with least privilege access (AmazonEC2ReadOnlyAccess and CloudWatchReadOnlyAccess).

## Result
AWS environment successfully configured with secure role-based access control for infrastructure setup and monitoring.
